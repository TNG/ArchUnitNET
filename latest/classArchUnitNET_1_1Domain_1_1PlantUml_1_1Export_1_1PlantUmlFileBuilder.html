PlantUmlFileBuilder ArchUnitNET.Domain.PlantUml.Export.PlantUmlFileBuilder.WithDependenciesFrom ( IEnumerable< Namespace > namespaces,
GenerationOptions generationOptions = null )

Draws the given namespaces as nested PlantUML namespaces, with an arrow from one namespace to another wherever one of its types depends on one of the other's. Parent namespaces that are not in the list are added so that the nesting is complete.

Parameters
namespacesThe namespaces to draw, e.g. Architecture.Namespaces.
generationOptionsFilters and layout options; the defaults if null. GenerationOptions.C4Style does not apply to namespaces.

PlantUmlFileBuilder ArchUnitNET.Domain.PlantUml.Export.PlantUmlFileBuilder.WithDependenciesFrom ( IEnumerable< Slice > slices,
GenerationOptions generationOptions = null )

Draws the given slices as components, with an arrow from one slice to another wherever one of its types depends on one of the other's.

Parameters
slicesThe slices to draw, e.g. from GivenSlices.GetObjects.
generationOptionsFilters and layout options; the defaults if null. With GenerationOptions.NestSlicesInPackages, every slice is drawn in the package of the deepest namespace that contains all of its types. With GenerationOptions.LimitDependencies, only the arrows between slices whose types share an equally deep namespace are drawn.
Exceptions
ArgumentExceptionTwo slices would be drawn under the same name.

PlantUmlFileBuilder ArchUnitNET.Domain.PlantUml.Export.PlantUmlFileBuilder.WithDependenciesFromFocusOn ( IEnumerable< Slice > slices,
string package,
GenerationOptions generationOptions = null )

Draws only the slices whose types all lie in the namespace package or below it, colored, and the slices they depend on or that depend on them, with the arrows between them that start or end at one of the former.

Parameters
slicesThe slices to draw, e.g. from GivenSlices.GetObjects.
packageThe namespace to focus on.
generationOptionsOnly GenerationOptions.NestSlicesInPackages is read; the defaults if null.
Exceptions
ArgumentExceptionThe package is empty, a single dot or a namespace that no slice lies in, or two slices would be drawn under the same name.
