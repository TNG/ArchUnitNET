Detailed Description

Defines how types are assigned to slices. The assignment function maps each type to a SliceIdentifier, and types with the same identifier are grouped into the same Slice.

Creates a new slice assignment with the given assignment function and description.

Parameters
assignIdentifierFuncA function that maps a type to a SliceIdentifier. Types that do not match the pattern should return SliceIdentifier.Ignore. Types it returns identifiers with the same parts for end up in the same slice.
descriptionA human-readable description of the assignment (e.g. matching "App.(*)").
